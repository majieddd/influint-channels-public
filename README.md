# Influint · Channel Intelligence (public view)

Public catalogue view of the channels Influint works with: video wall, durations
and outlier scores computed from **publicly visible view counts only**.

Retention figures, first-28-day windows, written analyses and the linked decks
are private to the Influint team and are not part of this build. They live in
the private knowledge base generated by the same code
(`buildSite(dir, "private")` in the creatorTools repo).
