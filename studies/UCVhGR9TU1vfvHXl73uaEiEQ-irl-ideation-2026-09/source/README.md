# Rebuilding the Nizar study

The original 100 ideas remain in `../ideas-original-2026-09-10.json`. Editorial rows, selected reference metadata and source snapshots live here. The supplied PDF documents were used as guidance and are not republished.

With Python 3 and beautifulsoup4 installed, run `python build-data.py`, then `python build-site.py` and `python build-download.py` from this directory. The first reads the selected channel catalogues in the repository, so later catalogue snapshots may change imported scores and coverage. The second builds the seven-section page and idea mappings from the JSON and current thumbnail manifest. The third packages all 125 thumbnails and prompts with checksum validation. CSS and JavaScript are maintained directly beside that JSON.

The five solo formats and 25 episode briefs are authored in `../solo-formats.json`. `solo_sections.py` renders their cards plus Creative, Production and Data Analysis additions. `idea_cards.py` supplies the shared visible card structure for all 125 ideas: a full-width Niz thumbnail, summary, three opening beats, and budget/download controls. Solo IDs 101-125 include direct source-video links, the original source-video thumbnails, relevance notes, and composition prompts. All 125 cards use one gallery, search, family/evidence filters, pagination and thumbnail modal. The five Niz-only formats are ordinary family-filter groups; there is no separate solo thumbnail gallery. Legacy format links select those groups. Solo source comparisons and evidence use the same disclosures as the original cards.

The original selected JPEGs, WebP previews and exact generation prompts are listed in `../thumbnail-manifest.json`. The 25 additional Niz thumbnail concepts are listed in `../solo-thumbnail-manifest.json` with source-video links, source thumbnails, prompt checksums, generated image checksums, and responsive WebP previews. The gallery download `../nizarisaqtirl-125-thumbnails.zip` contains all 125 JPEGs and prompts, plus both manifests. The original 100-image ZIP remains available at its existing URL. The available built-in image generator was used; its model identity is unverified and was not confirmed as GPT Image 2.5 Flare.

Commit the complete reviewed study first, then advance the content pin in `.github/scripts/persist-nizar-study.mjs` in a separate commit. That guard restores both missing assets and stale publisher-generated HTML before deployment. Do not invoke the older thumbnail-only integration script on this page.
